# Multiplayer mod: UI/UX flow review (2026-10-13)

Build reviewed: `build/dsrig.dylib` (04:31), sources in `src/` as of 04:30. Hidden copies on pair AB only (released), 1512x982 plus 960x540. `rig.py check-prefs`: identical.
Frames: `research/ux_shots/` (01-18 from the previous reviewer's run on the same build, 20-41 from this run), plus older frames from the test lanes (paths in section 2).
Not captured: story popup (no event in the test saves), level-up popup (no statue in the base save), the disconnect box at 1512 (the 960 frame exists), the refused-order toast (my script had a bug in that step). These items are reviewed from code only and say so.

Tag meanings: **RULE** = goes against an owner decision in PLAN.md. **BUG** = something does not work as designed. **OPINION** = my UX judgement; the owner decides.
