Dungeon Settlers MP: multiplayer version of Dungeon Settlers for Mac (Apple Silicon).
1. Install Dungeon Settlers with Steam and update it. Quit the game.
2. Open Terminal. Type: zsh ~/Downloads/DungeonSettlersMP/make_mp_app.sh  (change the path if you put this folder in a different location)
3. Start "Dungeon Settlers MP" from your Applications folder in your home folder. If Steam is not open, it starts by itself in the background (this can take up to a minute). If Steam asks you to sign in, sign in. If you see "Steam did not get ready", start Steam, sign in, then open Dungeon Settlers MP again.
Your normal game, saves and settings do not change. The MP app uses a copy of your saves.
