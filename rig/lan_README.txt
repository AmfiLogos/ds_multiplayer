Dungeon Settlers MP (LAN): personal test copy for the owner's second Mac. Do not share it. Apple Silicon Macs only (M1 or newer).
1. Unzip the file. Move "Dungeon Settlers MP (LAN).app" into your Applications folder.
2. Before the first start, open Terminal and type: xattr -dr com.apple.quarantine "/Applications/Dungeon Settlers MP (LAN).app"  (macOS blocks this test copy until you do this; on macOS 15 and later, right-click > Open does not work.)
3. When macOS asks about incoming network connections, click Allow. Steam is not necessary.
4. On the host Mac: Multiplayer > Host a game > Host from a save (or Host a new campaign). The lobby shows "Local: <address>"; "Copy direct address" copies it.
5. On this Mac: Multiplayer > Join by address, type or paste (Cmd+V) the host's Local address into the field, then click Connect.
