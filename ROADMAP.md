# Roadmap: Multiplayer mod

What we are working on, what comes next, and where you can help.

Updated: 2026-11-02

Dungeon Settlers Modded is made of three repos. Each item below is listed once, in the repo that does the work:

- **Multiplayer mod** (this repo): playing together, the Multiplayer page, the chat, the Foreign Expedition hub and PvP.
- **Mod loader** ([ds_modloader](https://github.com/AmfiLogos/ds_modloader), [its roadmap](https://github.com/AmfiLogos/ds_modloader/blob/main/ROADMAP.md)): the app, the Mods window, the Load Campaign list, the parts that every mod window shares (moving, the "-" and "+" size buttons), the installers.
- **Units Laboratory** ([ds_custommodes](https://github.com/AmfiLogos/ds_custommodes), [its roadmap](https://github.com/AmfiLogos/ds_custommodes/blob/main/ROADMAP.md)): My Units, the Unit Builder, the Wiki Build Gallery, Test Fights and the DPS Check.

## Now

- Nothing is being built for the multiplayer mod right now.

## Next

- Nothing is planned yet.

## Later / ideas

- **PvP: units that come back after they die.** Today a unit that dies in a PvP match stays dead.
- **A hub map built by a real player.** The Foreign Expedition hub is a full, finished base. A world built by a player (with that player's OK), or a map made for the hub, could look nicer.
- **Foreign Expedition with Steam Cloud.** So far we have only tested the hub on copies of saves. We want to test it with Steam Cloud saves turned on.

## Done

- **0.1.29 (2026-11-02, kit v0.1.30).** The chat's "-" and "+" buttons stay under your mouse when you click them. A right-click drag on the chat or the Players panel moves only the window on top.
- **0.1.28 (2026-10-26, kit v0.1.29).** Single player runs smoother with the multiplayer mod. The old "Foreign Expedition Hub" and "PvP Base" worlds no longer show in the Load list. A click anywhere on a Bring Units row ticks the unit. The chat has "-" and "+" size buttons.
- **0.1.27 (2026-10-25, kit v0.1.28).** You can move, resize and read the chat without typing. The multiplayer windows close with the game's red X or Escape and follow the game's UI Scale. Without Steam, your player name is never your computer account's name.
- **0.1.22 to 0.1.26 (2026-10-24 to 2026-10-25).** The hub leaves no save behind. A world new to multiplayer offers a single-player copy. A guest with Hell difficulty joins a Hell world with no restart. The multiplayer windows use the game's text look. Bring Units shows skill trees in your language.
- **0.1.17 to 0.1.21 (2026-10-21).** One mode, "Hub: Co-op or PvP": one shared map where you go on co-op expeditions or start PvP matches from the Esc menu. The hub is a full, finished base with the Guild Merchant, and its map comes inside the mod. Each PvP team sees only its own units and what they see. If your connection drops for a short time, the game joins again by itself. The chat shows accents, Cyrillic, Chinese, Japanese and Korean letters.
- **0.1.14 and 0.1.15 (2026-10-16).** PvP between a Mac host and a Windows player stays in sync. The Multiplayer page has "Host a game" and "Join a game" groups. Plainer text.
- **Earlier.** Every version is in the [CHANGELOG](CHANGELOG.md).

## Needs help / testing

Have you tried one of these? Please open an issue and tell us what happened.

- **A real Windows PC.** We have only tested Windows in a test setup on a Mac.
- **Steam on Windows.** Nobody has tested the Windows version with a real Steam install yet.
- **Playing over the internet.** We have not yet tested two players on different networks.
- **A world for the hub.** Do you have a good-looking, well-built world you would be happy to share? It could become the Foreign Expedition hub.

## Known issues

- Issues of the whole Dungeon Settlers Modded kit are on the [mod loader roadmap](https://github.com/AmfiLogos/ds_modloader/blob/main/ROADMAP.md). Please open an issue if you find one here.
